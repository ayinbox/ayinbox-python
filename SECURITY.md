# Security

Report a vulnerability in this library, or in the AY Inbox API it talks to, by email to team@ayinbox.com. Please do not open a public issue for it.

Include what you found, how to reproduce it and which version of `ayinbox` you used. We will acknowledge the report and keep you posted while we fix it.

Never include a real API key, webhook secret or customer data in a report or an issue. If a key was exposed, revoke it in the dashboard first.
